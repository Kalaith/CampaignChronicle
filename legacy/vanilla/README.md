# Archived Campaign Chronicle frontend

The root-level `index.html`, `app.js`, and `style.css` are retained for
historical reference and compatibility with old bookmarks. They are not a
supported product entrypoint and must not receive new features.

The supported entrypoint is `frontend/`, published at `/campaign_chronicle/`.
If the compatibility files are removed, do so only after confirming that no
external deployment still serves them.
